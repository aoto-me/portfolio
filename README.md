## 主な実装ポイント

### パフォーマンス

Core Web Vitals の基準（LCP 2.5秒以内・INP 200ms未満・CLS 0.1未満）のクリアを目標に、初期ロードへの影響が大きい箇所を中心に最適化しています。

- **Webフォントの非同期読み込み** — `next/font` はレンダリングブロックが生じたため今回は使用せず、`requestIdleCallback` でアイドル時に `<link>` を動的挿入
- **画像の遅延読み込み** — ファーストビューは `loading="eager"`、スライダー2枚目以降は `loading="lazy"` など画像ごとに読み込みタイミングを設定
- **Three.jsの遅延読み込み** — バンドルサイズが大きく、初期表示に悪影響を及ぼしたため、`next/dynamic` で初期バンドルから除外し、`requestIdleCallback` でレンダリング自体も遅延

### アクセシビリティ

WCAG 2.2 レベル AA を満たすことを目標として設計・実装し、自己チェックを実施しました。<br/>
自己チェックの結果は[ポートフォリオサイト](https://portfolio.1coffee9milk.com/works/portfolio#%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%83%93%E3%83%AA%E3%83%86%E3%82%A3%E3%81%B8%E3%81%AE%E5%AF%BE%E5%BF%9C)に掲載しています。

- **セマンティックHTML** — `header` / `main` / `nav` / `article` / `section` など適切な要素で文書構造をマークアップ
- **スクリーンリーダー** — 読み上げ時の内容や順序が自然になるよう、`aria-*` 属性や visually-hidden テキストを利用。NVDA（PC）とVoiceOver（スマホ）で読み上げ内容を確認
- **コントラスト比** — すべてのページのテキスト・非テキストでコントラスト比 4.5:1 以上を確保
- **カルーセルのフォーカス制御** — 非アクティブなスライドに `inert` と `tabindex="-1"` を動的に付与し、画面に見えないスライドへキーボードフォーカスが移動しないよう制御

### SEO

公開サイトは `noindex` / `nofollow` を設定しているため検索流入はありませんが、Webサイトとしての品質を考え、検索エンジンを意識した内部SEOを実装しています。

- **セマンティックHTML** — 適切なHTML要素で文書構造をマークアップし、検索エンジンとスクリーンリーダーの双方が内容を理解しやすい構造を実装
- **構造化データ（JSON-LD）** — トップページの作品一覧に `ItemList`、作品詳細ページに `CreativeWork` と `BreadcrumbList` を実装し、コンテンツの構造を検索エンジンや LLM に伝達
- **サイトマップ・robots.txt** — `sitemap.ts` / `robots.ts` で動的生成
- **OGP / Twitter Card** — SNS でシェアされた際の見た目(タイトル・画像・説明文)を指定するため、全ページの `head` に設定
- **llms.txt** — LLM が利用しやすいように、サイト概要や制作実績を `llms.txt` で提供
- **Google PageSpeed Insights** — SEOスコア100を達成し、内部SEOの実装状況を確認

### デザイン

青や紫を基調に、星やノイズ、装飾を組み合わせ、静かに流動する雰囲気を意識してデザインしました。<br/>
背景やページ遷移にはアニメーションを取り入れ、サイト全体の雰囲気を演出しています。

- **WebGL 背景** — Three.js を利用してテクスチャを歪ませた背景のゆらぎや星のパーティクルを実装
- **ページ遷移** — GSAP と SVG フィルターを利用してページが溶けるような遷移を演出
